# Project Rules & Guidelines (GEMINI.md)

## 1. Communication Language (بات چیت کی زبان)
- **Hamesha Roman Urdu / Roman English mein baat karein.**
- Urdu script (اردو رسم الخط) ke bajaye Roman English / Roman Urdu mein jawab dein taake user asaani se padh sakein.

## 2. Mandatory Approval Rule (پہلے بتانے کا لازمی اصول)
- **Kuch bhi karne se pehle USER ko batayein, phir karein.**
- Koi bhi code change, file edit, deployment ya configuration change karne se pehle clear explanation dein aur user se confirm karwayein.

## 3. Design & Theme System Rules (ڈیزائن کے اصول)
- **Sultani Emerald & Royal Gold Design System**:
  - Website ka design demo (`kil_royal_home_demo.html` / `demo.html`) ke 100% mutabiq hona chahiye.
  - Hero section mein koi nested "box inside box" nahi hona chahiye — balki ek wide, open, majestic Sultani frame hona chahiye.
  - Background par Islamic geometric gold lattice pattern aur ambient aura light barabar visible honi chahiye.
  - Search bar ke neeche "Maqbool Mozooaat" (Quick topics) aur "Hadith of the Day" banner zaroor shamil hona chahiye.
  - Navbar clean aur sleek gold links ke sath honi chahiye, clunky yellow pill buttons nahi hone chahiye.

## 4. Text & Content Authenticity (متن اور مواد کی حفاظت)
- **No "شاہی" (Shahi) words**: UI titles, badges, headings ya settings mein "شاہی" ka lafz bilkul use na karein.
- **Original & Authentic Text Only**: Apni taraf se koi naya ya self-invented text na daalein. Sirf website ka asli deeni text aur Quran/Hadith ke mustanad alfaz istemal karein.
- Backend ke asal kitaboon ke text ya records ko chhedne ki zaroorat nahi hai.
